# Repository ownership

This project is maintained in `Narehood/HomeAssistant-TV-Remote`.

- All pushes, pull requests, issues, comments, reactions, workflow dispatches, releases, and other repository mutations must target `Narehood/HomeAssistant-TV-Remote` only.
- `PRProd/HA-Firemote` is an upstream reference and is permanently read-only. Never perform a write or contribution action there, including through automatic tooling or default GitHub CLI repository selection.
- Explicitly verify the owner and repository before any GitHub mutation. Do not rely on fork-network defaults. Never open a pull request against the upstream repository.
- Preserve the original author and contributor credit, existing license, Git history, and third-party notices. Remove upstream funding and personal promotional links when implementing the fork cleanup.
- Upstream issues and pull requests may be read for requirements and technical evidence. Track their implementation locally or in this fork and use full upstream URLs as references.

The modernization audit and implementation sequence are in [docs/MODERNIZATION_PLAN.md](docs/MODERNIZATION_PLAN.md). The current audit does not authorize treating unverified device behavior as tested or fixed.
